# 镜流 · 无限画布

想想想 AI 视频里演示的镜流画布。把人物、场景、图片、音频和视频放在同一个工程里，从节点右侧拖线，选择下一镜使用哪些素材。

**[下载 Mac 版 ZIP](https://github.com/xiahuisen-ux/jingliu-canvas/releases/latest/download/Jingliu-Canvas-Mac.zip)**

解压后双击 **启动镜流.command**。首次启动需要联网安装网页服务的 Python 依赖和媒体工具。需要 Python 3.10 或以上，推荐 3.12。遇到 macOS 的脚本打开提示，可以在解压目录运行 `python3 app.py`。浏览器访问 `http://127.0.0.1:18772`。此时可以体验画布和媒体工具，无须下载生成模型。

## 跟着视频试一次

1. 打开随包的「落日航行」示例，播放视频节点。把第三张图片右侧的圆点拖到视频左侧，查看卡片下方新增的参考素材。已有的连线会随工程保存。
2. 点「场景」，在空白图块写提示词。配置 Z-Image 后可直接生图。点已有图片右边的圆点选「图片」，可继续连入多张参考图，用 Qwen 重绘。
3. 选中样片，在工具栏点「抽帧 → 尾帧」。右边会多一个真实图片节点，带有来源连线。可以接着重绘或连接到下一镜。抽帧和截取视频只需媒体工具。
4. 切到「画布＋对话」。在顶部「文字模型」配置兼容 API 或本地模型。选中节点并点「引用选中」，助手可围绕这个素材建节点、写提示词、抽帧和裁剪。使用云端模型时，按界面说明将对话及相应上下文发送到你配置的服务。
5. 从「资产库」跨工程复用素材。在视频节点可查看历史版本，选择参考模式、首帧或尾帧。配置可选后端后可使用超分、面部精修和 MuseTalk 口型。

## 接入模型

点击画布右上角 **? → 模型下载地址与安装位置**。下载包提供网页、后端适配代码和下载地址；权重由使用者自行获取。

- [模型地址、目录和 Apple 芯片 Mac 安装步骤](教程/模型接入.md)
- [给智能助手的部署指令](教程/01-部署指令.txt)
- [给智能助手的无限画布需求](教程/02-无限画布需求.txt)

完整画布的工程、模型连接配置和素材库存放在 `~/Library/Application Support/Jingliu Canvas Studio/`。可用 `JINGLIU_DATA` 更换数据位置，用 `JINGLIU_BACKENDS` 指向已有后端的父目录。升级前可备份数据目录。关闭启动终端即可结束本机服务。

## 已用过 v0.1 的用户

新版默认进入视频中的工作台。原轻量版工程可继续用 **打开旧版画布.command** 打开，使用原端口 18771 和原数据目录 `~/Library/Application Support/Jingliu Canvas/`。两个工程格式不同。要在新版继续使用旧工程的生成结果，可通过「导入素材」导入图片、音频或视频。[旧版说明](教程/轻量版使用说明.md)

修改新版界面请进入 `workbench/canvas-ui/` 运行 `npm ci`、`npm run build`。发布包已经内置构建结果，观众无需安装 Node。前端和适配器的上游许可附在相应目录。

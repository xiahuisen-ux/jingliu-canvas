# 完整画布的后端接入

默认后端根目录是 `~/Library/Application Support/Jingliu Canvas Studio/backends`，以下相对目录以此为起点。已部署过同款后端的用户，可以在终端给 `JINGLIU_BACKENDS` 指定已有的父目录再启动。网页及各个模型独立运行，可按所需功能安装。

## 画布助手、文生图和多图重绘

- 文字模型可在画布顶部「文字模型 → 参数」设置。选兼容接口，填自己的地址、模型 ID、密钥。或者在本机安装 Ollama，使用配置的文字模型。密钥保存在当前用户应用数据目录中。
- 安装 [ComfyUI](https://github.com/Comfy-Org/ComfyUI) 至 `Qwen-Image/ComfyUI`，按其说明构建可运行的 Python 环境。默认使用其 `venv/bin/python`。为 Qwen GGUF 重绘安装 [ComfyUI-GGUF](https://github.com/city96/ComfyUI-GGUF) 并安装节点依赖。
- [图片模型分文件地址](../web/models.json) 列出 Z-Image-Turbo、Qwen-Image-Edit-2511、编码器、VAE、LoRA 及相应子目录，和画布帮助里的下载页对应。模型文件放进 **ComfyUI** 的 `models/`。画布会按工程启动 ComfyUI 并设置独立的输入输出目录。
- 已有 ComfyUI 可在应用数据目录创建 `backends.json`，设置 `qwen_image_root`、`qwen_image_python` 和 `qwen_image_url`。前两项填写自己的绝对路径，后者填写本机专用服务地址，例如 `http://127.0.0.1:8188`。本地文字模型可用 `ollama_model` 和 `ollama_url` 设置。保存后重新启动镜流。

## MiniMax H3 视频（Apple Silicon）

需要 Xcode Command Line Tools、Git，以及能运行 Metal 的 Apple 芯片 Mac。先在解压后的镜流目录打开终端，以下命令把与本版画布配套的推理程序编译到新目录。若已有同款已打补丁的程序，可直接复用。

```sh
package_dir="$PWD"
backend_root="${JINGLIU_BACKENDS:-$HOME/Library/Application Support/Jingliu Canvas Studio/backends}"
mkdir -p "$backend_root/H3C-Metal部署"
git clone https://github.com/antirez/h3.c.git "$backend_root/H3C-Metal部署/source"
cd "$backend_root/H3C-Metal部署/source"
git checkout 8974cc055ea9c02fcd14cc27dfda3e1027c05153
git apply "$package_dir/backend-adapters/h3/mirrorflow.patch"
make -j4 h3 h3-worker
./h3-worker --validate </dev/null
```

从 MiniMax 模型仓库分别下载 [Ref2VA](https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/Ref2VA) 和 [FL2VA](https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/FL2VA) 的完整目录（含索引、分片、tokenizer、视频与音频 VAE），并列放入 `H3C-Metal部署/models/MiniMax-H3/`。单个索引文件不足以运行模型。FFmpeg 和 FFprobe 由画布启动器准备；已有 FFprobe 也可通过 `JINGLIU_FFPROBE` 指定。校验模式只检查工作进程协议，实际生成需另跑样片。

## 可选增强与口型

| 功能 | 下载与接入 |
| --- | --- |
| 视频与图片超分 | 从 [Real-ESRGAN ncnn Vulkan 发布页](https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan/releases) 获取 macOS 工具，把可执行文件放到 `Real-ESRGAN部署/realesrgan-ncnn-vulkan-v0.2.0-macos/realesrgan-ncnn-vulkan`，将 realesrgan-x4plus.param 和 .bin 放到 `Real-ESRGAN部署/models/`。 |
| H3 FaceRefine | 在 `H3FaceRefine-Metal/upstream` 放置 [FaceRefine 源码](https://github.com/Carasibana/ComfyUI-H3-FaceRefine/tree/d8521d14fe0d721d80cd9417fff5a559cbc21aba)，[检测权重](https://huggingface.co/Bingsu/adetailer/resolve/main/face_yolov8n.pt) 放到同级 `models/`。把随包 `backend-adapters/facerefine/face_runtime.py` 放到 `H3FaceRefine-Metal/`，在该目录建立 Python 3.12 独立环境 `venv` 并按附带的 requirements.lock.txt 安装依赖。还需要上面的 H3 worker 和权重。 |
| MuseTalk 1.5 | 将 `backend-adapters/musetalk/` 的内容复制到 `MuseTalk-Metal部署/`。把 [Apple 芯片适配源码](https://github.com/stefanskiasan/MuseTalk-Metal/tree/895747b82968320282dc9e20245ca7ded81aa79d) 放到其中的 `source/`，建立 Python 3.12 独立环境 `venv`，执行 `venv/bin/python -m pip install -r requirements.lock.txt`。在部署目录执行 `venv/bin/python download_models.py` 下载清单中的权重。按 [上游模型清单](https://github.com/TMElyralab/MuseTalk/blob/main/download_weights.sh) 另取 face-parse 的 79999_iter.pth，放入 `source/models/face-parse-bisent/`。最后执行 `venv/bin/python configure.py`，校验本机路径、环境、权重并写入 runtime.json。 |

只需抽帧、裁剪、移动或连接节点时，无须上述模型。生成模型的实际速度和输出取决于安装版本、内存和输入素材。

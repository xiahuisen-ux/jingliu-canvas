# 镜流 · 无限画布轻量版

想想想 AI 频道的本地画布。可以拖动素材、连接图片、播放样片、保存节点和提示词。画布界面与示例均在本机运行，生成工具按需连接。

**[下载 Mac 版 ZIP](https://github.com/xiahuisen-ux/jingliu-canvas/releases/download/v0.1.0/Jingliu-Canvas-Mac.zip)**

## 第一次打开

1. 在 Mac 上解压 ZIP，双击文件夹里的「启动镜流.command」。需要 Python 3.9 或更新版本，可从 [Python 官网](https://www.python.org/downloads/macos/) 安装。
2. 浏览器打开本机画布。点击「落日航行」的播放按钮可看五秒示例。该示例是随包制作的动画。
3. 从「落日色调」右侧的小圆点拖到视频节点左侧的小圆点。右侧属性应显示三张参考图。等右上角显示「已保存」，刷新页面，连线仍然存在。
4. 点击「导入图片」可使用自己的素材。点一条连线再选「断开选中连线」可更换参考图。拖动空白处平移，滚动缩放。

关闭启动窗口会结束本地服务。若双击时系统提示无法打开脚本，可在终端中进入解压后的文件夹，运行 `python3 app.py`。本地地址是 `http://127.0.0.1:18771`。画布、上传素材、生成结果、连接配置保存在 `~/Library/Application Support/Jingliu Canvas/`。备份时复制整个目录。

## 使用自己的模型

点右上角「模型设置」，按用途查看下载页、文件名和目标目录。只体验画布即可使用内置素材。点击生成会使用你自己配置的本机算力。

| 想做什么 | 配置什么 |
| --- | --- |
| 文生图 | 启动本机 ComfyUI，安装 Z-Image-Turbo、文字编码器和 VAE。在设置中填 ComfyUI 地址，通常为 `http://127.0.0.1:8188`。 |
| 用参考图重绘 | 在同一 ComfyUI 安装 ComfyUI-GGUF 节点、Qwen-Image-Edit-2511 Q5_K_M、对应编码器、VAE 和八步 LoRA。可连入一至三张图。 |
| 在 Apple 芯片 Mac 上生成视频 | 按 [h3.c 上游说明](https://github.com/antirez/h3.c) 编译 h3，安装 FFmpeg 与 FFprobe。下载 [MiniMax H3 的 Ref2VA](https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/Ref2VA)，在设置中选择包含 Ref2VA 的目录及 h3 可执行文件。 |

ComfyUI 工作流位于 `workflows/`，是提交给本地 API 的 JSON。所有权重请按来源页面的许可获取。首次配置时检查模型文件的总大小和硬盘剩余空间。H3 以 512 × 288、8 步、约五秒请求启动，片长由后端的合法帧数决定。检测通过表示所需文件、节点或工具可以找到，实际生成仍受内存、后端版本和设备性能影响。

## 修改界面

运行成品仅依赖 Python 标准库。网页资源已经构建并随包提供。修改 `src/` 后，在源码目录运行 `npm ci` 和 `npm run build`。前端使用 React 与 React Flow，依赖许可见 [随包声明](../THIRD_PARTY_NOTICES.txt)。
